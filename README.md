# BlockSlayer

**INNNX. · Flutter 方块消除与战斗原型**

本仓库展示当前本地项目，源码保持私有。

## 当前实现

- 方块拖放、棋盘与消行逻辑。
- 史莱姆生命值与消行伤害计算。
- 按放置次数触发的敌方回合逻辑及攻击反馈组件。
- 本地音频、主题与持久化相关组件。

这些内容来自现有实现的静态检查；本次上传未重新运行游戏或验证发布构建，不代表完整成品。

## 技术栈

Flutter、Dart、Provider、SharedPreferences、flutter_animate、audioplayers；工程还包含截图和分享依赖。
